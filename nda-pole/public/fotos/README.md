# Fotos del sitio

Poné acá las fotos reales. El sitio ya está preparado para usarlas:

- **`hero.jpg`** → foto principal del inicio (vertical, recomendado 1080×1350 px / formato 4:5).
  Si no existe, el hero muestra un fondo pastel liso igual (no se rompe nada).

Sugerencias:
- Usá fotos en la gama de las que pasaste (caramelo / verde menta / crema) para que peguen con la paleta.
- Optimizá el peso (idealmente < 400 KB) para que cargue rápido en celu.
- Podés agregar más fotos y referenciarlas editando `src/components/Hero.tsx`.
